# BIT235 Workshop 2

This project contains the Java programs for Workshop 2:
Fundamental Programming Structures in Java.

## Programs

| Exercise | File | Purpose |
|---|---|---|
| 1.1 | `DifferenceOfTwoNumbers.java` | Reads two integers and displays their difference |
| 1.2 | `CelsiusToFahrenheit.java` | Converts Celsius to Fahrenheit |
| 1.3 | `AreaOfCircle.java` | Calculates the area of a circle using `Math.pow` |
| 1.4 | `CompoundInterest.java` | Calculates compound interest |
| 1.5 | `SunEarthVolume.java` | Calculates and compares sphere volumes |
| 1.6 | `FuelConsumption.java` | Calculates travel distance on normal and rough roads |
| 1.8 | `CompareStrings.java` | Compares two strings and their first characters |

Exercise 1.7 is a written question rather than a Java program:

```text
"I love java programming".substring(7, 11)
```

The returned string is `"java"`, and its length is `4`.

## Compile and run

Open a terminal in this folder and compile all programs:

```bash
javac *.java
```

Run a program by using its class name, for example:

```bash
java DifferenceOfTwoNumbers
java CelsiusToFahrenheit
java AreaOfCircle
java CompareStrings
```

The other programs do not require keyboard input:

```bash
java CompoundInterest
java SunEarthVolume
java FuelConsumption
```
